- Zara est **jouable immédiatement** : le Product Owner doit voir le progrès dès le premier écran.
- Le Chapitre 2 prolonge la saga sans effacer le Chapitre 1 ; les anciennes sauvegardes terminées reprennent au combat 4.
- Les défis utilisent les statistiques déjà suivies par le profil afin de rester compatibles avec les sauvegardes V2.0 → V2.3.
- Les replays restent un chantier technique séparé : ce sprint privilégie le contenu jouable et visible.
